# Zimone Jumpscare

**The Commander:** **Zimone, Mystery Unraveler** — a {G}{U} Simic landfall /
lands-matter engine. The deck ramps hard, floods the board with lands and
land-creatures, and turns extra land drops into card advantage and big Simic
payoffs (Worldspine Wurm, Hydra Omnivore, Overwhelming Stampede).

**Archetype:** Simic (Green/Blue) landfall + lands-matter value
