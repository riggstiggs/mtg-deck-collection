# Twincasters

**The Commander:** **Adrix and Nev, Twincasters** — a {G}{U} Simic commander that
DOUBLES the tokens you create. Build a Fractal/token engine, layer more doublers
(Parallel Lives, Second Harvest, Doubling-style effects), and go wide fast, then
close with Overwhelming Stampede / big Simic payoffs.

**Archetype:** Simic (Green/Blue) token doublers + Fractals
